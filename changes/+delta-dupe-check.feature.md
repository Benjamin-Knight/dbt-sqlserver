`table_refresh_method: delta` checks the scratch table for duplicate rows with a much smaller memory grant. The check now aggregates the full-width row only over rows whose `CHECKSUM` collides with another's, and, when the model sets `delta_key` (a column name or list of names), skips it entirely once that key is unique. A key that is not unique falls back to the exact check, so configuring one never hides a duplicate; a name that is not a column fails the run. The model's `query_options` (for example `max_grant_percent`) now also apply to the duplicate check, the churn insert and the delta `DELETE`.
