Add `table_refresh_method: delta`, an opt-in variant of `dml` that deletes and inserts only the rows that differ between the table and the new build. It falls back to the full `dml` swap, in the same transaction, on duplicate rows or when more than 15% of the rows would be deleted. Rows are compared under each column's collation, so a case-only change under a case-insensitive collation is not written; see the README for this and the other limitations.
